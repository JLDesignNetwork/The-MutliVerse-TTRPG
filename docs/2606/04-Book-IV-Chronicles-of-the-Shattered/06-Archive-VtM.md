# The Infinite Archive: Vampire The Masquerade

This archive provides Vector baselines for the Kindred of Vampire: The Masquerade. In VtM, a vampire's Clan dictates both their physiological "Race" and their mechanical "Class" via Disciplines.

## Core Origin (All Vampires)
All vampires possess the following baseline regardless of Clan:
*   **Origin Tag:** [Origin: Ascendant] (Undead)
*   **Innate Traits:** [Trait: Defense Resistant Kinetic] (halves bullet/blunt trauma), [Trait: Defense Vulnerable Thermal] (Fire/Sunlight), [Path Feature: Hunger X] (Requires blood to use Slots).
