> **Document:** `docs/usage.md`  
> **Author:** Jeff Langdon (JL Design Network)  

---

## 1. Running Campaigns

1. **Establish the Starting Shard:** Choose an anchor realm (High Tech, Mythic Fantasy, or Void Wasteland).
2. **Set Dimensional Stability Rating:** Determine the party's Reality Tether (1–10).
3. **Handle Planar Incursions:** Use the hazard tables in Book I when characters cross Shard thresholds.

---

## 2. Next.js Web Companion Development

### Local Dev Server
```bash
# Start Next.js development server
pnpm dev
# Server accessible at http://localhost:3000
```

### Production Build & Linting
```bash
# Build Next.js application
pnpm build

# Run TypeScript / ESLint checks
pnpm lint
```
